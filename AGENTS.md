# Instructions for coding agents in this repository

This file applies only when someone adds or changes a skill or package under `skills/`
and is getting ready to submit it. It does not apply to work on `scripts/`, `.github/`,
`tests/`, `docs/`, or anything else. For that, follow the normal instructions you were given.

## Contributing a skill

When the user adds or changes a skill or package under `skills/` and is about to open
a Pull Request, or says they are done or want to submit it:

1. Read and follow [`docs/skill-contribution-check/SKILL.md`](docs/skill-contribution-check/SKILL.md) first.
2. Share its report, then fix the **Must fix** items only with the user's agreement.
3. Never push or open the Pull Request on the user's behalf unless they ask, and never promise that it will be approved. Maintainers decide.

The full rules are in [CONTRIBUTING.md](CONTRIBUTING.md).
