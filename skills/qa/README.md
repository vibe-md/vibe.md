# QA & Automation Package

A comprehensive, engineering-grade collection of skills for software testing, quality assurance, and test automation. This package equips AI agents with the best practices to plan, write, investigate, and automate robust test suites across different layers of the software architecture.

## Categories

**Planning & Analysis**
- `qa-test-strategy`: Test Strategy & Planning
- `qa-change-impact-analysis`: Change Impact & Logic Regression Analysis

**Test Automation**
- `qa-unit-testing`: Unit & Integration Testing
- `qa-api-testing`: API & Backend Testing
- `qa-e2e-playwright`: End-to-End (E2E) Testing
- `qa-visual-regression`: Visual Regression Testing
- `qa-accessibility-testing`: Accessibility (a11y) Testing

**Quality & Reliability**
- `qa-performance-testing`: Performance & Load Testing
- `qa-bug-triage`: Bug Investigation & Triage

**Delivery & Automation**
- `qa-ci-cd-pipelines`: CI/CD Testing Automation
