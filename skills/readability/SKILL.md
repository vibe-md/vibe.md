# Readability

## Purpose
Transform dense, raw, or unstructured text into clear, well-structured, and professional documentation with proper formatting, consistent tone, and high readability.

## When to Use
- Refining markdown files, documentation, or technical notes.
- Cleaning up raw transcripts or notes into organized, logical sections.
- Improving the flow, grammar, sentence structure, and overall clarity of written content.

## Instructions
1. **Analyze:** Review the target text for flow, grammar, logical progression, and clarity issues.
2. **Structure:** Restructure sections using clear headings, subheadings, and bullet points where appropriate to break down complex ideas.
3. **Tone:** Ensure a professional, objective, and consistent tone throughout the entire document.
4. **Preserve Integrity:** Strictly preserve technical accuracy, code snippets, configuration blocks, commands, and critical links without altering their original meaning or syntax.

## Examples
*User:* "Can you clean up these raw notes and make them a readable guide?"
*Agent:* Analyzes the raw notes, organizes them with proper markdown headings, formats lists cleanly, and presents a polished guide while keeping all technical details and code snippets completely intact.
